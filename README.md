# workflow-experiments

# Why

I have implemented workflow / durable execution engines several times in my previous jobs. I have always enjoyed solving this problem. In a way it touch a lot of distributed system concepts that I have grown to enjoy over time. This is an attempt to learn Rust by implementing a workflow / durable execution engine again from first principles. My hope is that once I have covered a reasonable surface of the problem, I will comfortable using Rust day to day.
